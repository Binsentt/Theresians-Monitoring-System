# 🎓 Theresian's Quest - Monitoring System

A full-stack web-based monitoring and learning management system developed for **Theresian's Quest**, an educational 2D RPG game. The platform allows administrators, teachers, and parents to manage student learning progress, lessons, quizzes, announcements, and game-related data through a modern and responsive web interface.

---

## 🌟 Features

### 👨‍💼 Admin
- Manage users and roles
- Dashboard with system overview
- Student management
- Teacher management
- Parent management
- Announcement management
- Leaderboard management

### 👩‍🏫 Teacher
- Create and manage lessons
- Upload learning materials
- Manage quizzes and questions
- Monitor student progress
- View leaderboard

### 👨‍👩‍👧 Parent
- View child's learning progress
- Monitor quiz results
- Track completed lessons
- View announcements

### 🎮 Game Integration
- Student progress synchronization
- Quiz result recording
- Leaderboard integration
- Player statistics management
- API-ready for Godot integration

# 🚀 Installation

## Clone the repository

```bash
git clone https://github.com/Binsentt/Theresians-Quest-Web.git
```

## Install dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd server
npm install
```

---

# ▶ Run the Application

### Frontend

```bash
npm start
```

### Backend

```bash
npm run dev
```

---

# 🗄 Database

Database: **PostgreSQL**

Configure your environment variables:

```env
DATABASE_URL=your_postgresql_connection
PORT=5000
JWT_SECRET=your_secret_key
```
